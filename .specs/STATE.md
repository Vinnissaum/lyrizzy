# Project state

The project's decisions D-1..D-90 live in `.specs/project/STATE.md`. From phase 22 on, new
decisions are logged here as `AD-091` onward, because tlc-spec-lean's validators read this file.

## Decisions

| ID | Decision | Rationale | Status | Date |
| --- | --- | --- | --- | --- |
| AD-091 | Phase 22: while presenting, every song row in the set pane has an edit control beside its remove control, the song on screen included; it opens the song editor dialog `Editar letra` already uses, with no extra confirm step, and changes neither the current item nor the wall. Other item types get no edit control. The set pane keeps its 240 px width, so a song row's title and artist truncate about 30 px sooner | Departs from `captures/operator-many-slides.png`, which draws song rows with the remove control only. User request 2026-10-28: "add a small button to edit and open a dialog to confirm". Asked "What should the small edit button open?" - chose "Editor directly (Recommended)"; asked "Which songs should get the edit button?" - chose "Every song, on-air too (Recommended)" | active | 2026-10-28 |
| AD-092 | Phase 22: strophe cards in the operator strophes pane never overlap. Each grid row is as tall as its cards (`grid-auto-rows: max-content`), so a long song scrolls instead of squeezing rows into the pane's height | Departs from `captures/operator-many-slides.png`, which draws rows 95 px apart for 127 px cards. User request 2026-10-28: "add to these feature the fix of song 'slides' show overflowing another when it has a large number of slides as you can see on printscreen" | active | 2026-10-28 |
| AD-093 | Phase 23: the countdown editor opened from a set row while presenting is Home's dialog (`Configurar cronômetro`) and saves to the set item. A save restarts a countdown counting from that item only when its target (duration or clock time) changed; any other change restyles it and it keeps counting. D-89 still governs the `+1/+5/−1 min` strip, which stays run-only. Countdown rows therefore get an edit control, which replaces AD-091's "Other item types get no edit control" for countdowns only | User request 2026-11-16: "Add full editing capabilities for the countdown timer while in presenter mode". Asked "What should full editing of the countdown while presenting be?" - chose "Home's editor, saved (Recommended)"; asked "When you save an edit to the countdown that is counting on the wall right now, what happens to the running time?" - chose "Restart only if time changed (Recommended)" | active | 2026-11-16 |
| AD-094 | Phase 23: a video set item's playback state (position, duration, paused, muted, ended) lives in the wall's `<video>` element, not in `AppState`. The presentation window reports it with the frontend event `video_report` and obeys the operator's `video_command`; both go through `src/api/commands.ts`, as `forward_keydown` does. The presentation window still invokes no mutating command. Live video controls (pause, restart, seek, skip, mute) are run-only and never write `set_items.media_options` | A clock held in Rust cannot know the element's real position, and has no duration when ffprobe is absent (`Media.durationMs` is optional); a `report_video_progress` command would break the read-only presentation window. User, 2026-11-16, asked which extra video controls: "Seek on the progress bar, Skip -10 s / +10 s, Mute / unmute" | active | 2026-11-16 |
| AD-095 | Phase 23: set items can be reordered while presenting, the item on screen included. The new order is saved to the set and applied to every output that has the set loaded; each output keeps the item, slide and frozen item it shows (extends D-88). `reorder_set_items` refuses an id list that is not a permutation of the set's items with `set.reorder_mismatch` | User request 2026-11-16: "Enable the ability to drag and drop items within the set in presenter mode". Supersedes phase 21's out-of-scope rows "Reordering items while presenting" and "Live sync of duplicate and reorder" for reorder. Moving a row changes order, never content, so nothing on a wall depends on it | active | 2026-11-16 |
